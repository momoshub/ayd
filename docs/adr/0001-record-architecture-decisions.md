# 1. Record architecture decisions

Date: 2026-09-24

## Status

Accepted

## Context

This is an AI-first repo: agents and humans need the _why_ behind the structure, not just
the code, to make changes that fit.

## Decision

We record every significant architectural decision as a short ADR in `docs/adr/`, numbered
and dated, in the [Nygard format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

## Consequences

Decisions are discoverable and revisable. A new ADR supersedes an old one rather than
editing history; the old one stays with status `Superseded by NNNN`.
